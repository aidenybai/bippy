# Writing guidelines

Before you start:

1. Fetch and read [the current rules](https://aidenybai.com/blog/write.md).
2. Read `sample/opencode-reloaded.md`. Study how its headings, examples, and paragraphs build one argument. Copy its structure, not its voice.

## Writing new text

1. Read the code, docs, and history behind the subject. If they don't answer a question, ask instead of guessing.
2. Pick the content type from the rules.
3. Outline the headings, then draft each section.
4. Grade the draft before you return it.

## Grading and revising text

Check the text against every rule. After you revise, check the revised text again.
